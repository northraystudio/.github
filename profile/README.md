# NorthRay Studio

ともに考え、ともに実践する。

NorthRay Studio は、技術戦略から開発、セキュリティまで、助言にとどまらず実践まで支援する会社です。
現場の課題から生まれた仕組みを、オープンソースとして公開しています。

| リポジトリ | 内容 |
|---|---|
| [sakuda](https://github.com/northraystudio/sakuda) | Webアプリの脆弱性スキャン環境を、Docker ひとつで用意できます。 |
| [maruda](https://github.com/northraystudio/maruda) | AIを使った開発に、品質とセキュリティの確認を組み込む仕組みです。 |
| [pmotto](https://github.com/northraystudio/pmotto) | プロジェクトの工数・コスト・進捗をまとめて把握する基盤です（検証段階）。 |
| [self-management-template](https://github.com/northraystudio/self-management-template) | 情報整理をAIに任せて判断に集中する、自分用に育てるテンプレートです。 |
